# Source batch 004

Recorded as a visual-layout preference on 2026-09-02. This batch describes
rendering preferences only and changes no relationship fact.

- Married spouses must stay physically adjacent inside one compact couple
  unit; no spouse pair should be stretched across a huge horizontal gap.
- The marriage line (horizontal, between the two spouses) and the child
  routing junction (separate, below the couple) are two distinct concepts.
- Maternal-side couple units use different subtle pale pink shades.
- Paternal-side couple units use different subtle pale blue shades.
- Irsa Naz + Mansoor Hussain visibly combine both sides (pink on Irsa's
  card, blue on Mansoor's card) instead of being colored one single way.
- The brothers / بھائی and sisters / بہنیں cross relationships stay neutral
  (gray, dashed/dotted) and secondary to the main genealogy.
- No permanent future-cousin layout rules (second/third cousins, cousin
  marriages, distant cross-family relations, branch widths, or generation
  maximums) have been decided yet; the renderer must stay flexible.
