# Repository Structure & Path Migration Manifest

**Migration Date:** 2026-09-04  
**App Version:** 1.0.0  
**Data Root Version:** 1  

## Overview

The **Family Relationships** repository was restructured to establish four clear top-level conceptual directories:

- **`Codebase/`**: All application source code, desktop shell, tests, scripts, and build configurations.
- **`Database/`**: Active SQLite relationship store, per-person markdown journals, runtime configurations, evidence sources, and generated output exports.
- **`Backups/`**: Manual, automatic, and safety pre-operation snapshot backups with SHA-256 manifests.
- **`Documentation/`**: Project architecture, API, database, UI screenshots, and historical archives.

## Canonical Data Resolution

All runtime paths are dynamically resolved via `DataRootManager`:
- Database path: `Database/Main/family.db`
- People directory: `Database/People/`
- Config directory: `Database/Config/`
- Backups directory: `Backups/`
- Exports directory: `Database/Exports/`
